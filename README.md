📝 Blog con Editor Avanzado en Django y QuillJS (Migrado a PostgreSQL)
Sistema de gestión de contenido (CMS) moderno desarrollado con Django y PostgreSQL, que permite crear, editar y publicar artículos utilizando un editor de texto enriquecido. Este proyecto ha sido migrado desde MySQL a PostgreSQL para mejorar la integridad de datos, compatibilidad con entornos CI/CD y escalabilidad profesional.

✨ Características Técnicas
Editor de Texto Enriquecido: Integración con QuillJS para edición visual avanzada.

Interfaz Responsive: Diseño adaptable con Bootstrap 5.

Base de Datos PostgreSQL: Migración completa desde MySQL, con validación de estructura y compatibilidad con Django ORM.

Panel Administrativo: Gestión de contenido desde el backend de Django.

Entorno Virtual y Dependencias: Instalación aislada con venv y requirements.txt.

🚀 Funcionalidad
Crear y editar posts con QuillJS.

Visualización de posts en tarjetas Bootstrap.

Soporte para emojis y caracteres especiales.

Acceso al panel /admin para gestión de contenido.

📌 Rutas Clave
/ → Lista de publicaciones.

/new/ → Crear nuevo post.
